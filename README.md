# The War of the West

Game builds and patch notes, installed and kept up to date by the launcher.

## Play
1. Download **WarOfTheWest-Setup-x.y.z.exe** from the newest [launcher release](https://github.com/morgansjomark/war-of-the-west-releases/releases?q=launcher&expanded=true) and run it (Windows 10/11).
   Windows SmartScreen may warn about an unknown publisher: *More info* → *Run anyway*.
2. In the launcher press **Install**, then **Play**. New versions download automatically when the launcher starts; only changed files are fetched.
3. Co-op: one player picks *Host online* in the game and shares the join code; the others join with it (up to three heroes).

Patch notes are on each `game-v*` release and in the launcher's *Chronicle* tab.

Releases here are never deleted: later versions reuse files uploaded by earlier ones.
